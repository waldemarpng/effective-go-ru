## Указатели и значения

[оригинал](https://go.dev/doc/effective_go#pointers_vs_values)

Как мы видели на `ByteSize`, методы можно определять для любого именованного типа (кроме указателя или интерфейса); получатель не обязан быть структурой.

В обсуждении слайсов выше мы написали функцию `Append`. Вместо этого можно определить её как метод на слайсах. Для этого сначала объявим именованный тип, к которому можно привязать метод, а затем сделаем получателем метода значение этого типа.

```
type ByteSlice []byte

func (slice ByteSlice) Append(data []byte) []byte {
    // Body exactly the same as the Append function defined above.
}
```

Это всё ещё требует, чтобы метод возвращал обновлённый слайс. Неуклюжесть можно убрать, переопределив метод так, чтобы получателем был указатель на `ByteSlice`: тогда метод сможет перезаписать слайс вызывающего.

```
func (p *ByteSlice) Append(data []byte) {
    slice := *p
    // Body as above, without the return.
    *p = slice
}
```

На самом деле можно ещё лучше. Если изменить функцию так, чтобы она выглядела как стандартный метод `Write`, вот так,

```
func (p *ByteSlice) Write(data []byte) (n int, err error) {
    slice := *p
    // Again as above.
    *p = slice
    return len(data), nil
}
```

то тип `*ByteSlice` удовлетворяет стандартному интерфейсу `io.Writer`, что удобно. Например, в него можно печатать.

```
    var b ByteSlice
    fmt.Fprintf(&b, "This hour has %d days\n", 7)
```

Мы передаём адрес `ByteSlice`, потому что только `*ByteSlice` удовлетворяет `io.Writer`. Правило про указатели и значения для получателей такое: методы со значением можно вызывать и на указателях, и на значениях, а методы с указателем — только на указателях.

Это правило возникает потому, что методы с указателем могут менять получателя; вызов их на значении заставил бы метод получить копию, и любые изменения пропали бы. Поэтому язык запрещает эту ошибку. Есть удобное исключение. Когда значение адресуемо, язык берёт на себя обычный случай вызова метода с указателем на значении и автоматически вставляет оператор адреса. В нашем примере переменная `b` адресуема, так что можно вызвать её метод `Write` просто как `b.Write`. Компилятор перепишет это в `(&b).Write`.

Кстати, идея использовать `Write` на слайсе байт лежит в основе реализации `bytes.Buffer`.
