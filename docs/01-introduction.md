# Введение

[оригинал](https://go.dev/doc/effective_go#introduction)

Go — язык программирования с открытым исходным кодом. Он сделан простым, надёжным и эффективным, чтобы на нём было удобно строить ПО в большом масштабе. Хотя Go заимствует идеи у существующих языков, у него есть необычные свойства, из‑за которых хороший код на Go по характеру отличается от программ на родственных языках. Прямой перевод программы с C++ или Java на Go вряд ли даст удачный результат — программы на Java пишут на Java, а не на Go. С другой стороны, если посмотреть на задачу с точки зрения Go, может получиться успешная, но совсем другая программа. Иначе говоря, чтобы хорошо писать на Go, важно понимать его свойства и идиомы. Важно также знать принятые соглашения: именование, форматирование, устройство программ и так далее, — чтобы другим программистам на Go было легко вас понять.

Этот документ даёт советы, как писать ясный идиоматичный код на Go. Он дополняет [спецификацию языка](https://go.dev/ref/spec), [Tour of Go](https://go.dev/tour/) и [How to Write Go Code](https://go.dev/doc/code); их стоит прочитать сначала.

> **Сейчас.** Effective Go не покрывает модули и дженерики. Актуальная документация: [How to Write Go Code](https://go.dev/doc/code), [Using Go Modules](https://go.dev/blog/using-go-modules), [Tutorial: generics](https://go.dev/doc/tutorial/generics), [заметки о релизах](https://go.dev/doc/devel/release).
