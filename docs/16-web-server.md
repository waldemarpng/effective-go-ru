# Веб-сервер

[оригинал](https://go.dev/doc/effective_go#web_server)

Закончим полной программой на Go — веб‑сервером. На самом деле это своего рода веб‑пересервер. Google даёт службу на `chart.apis.google.com`, которая автоматически оформляет данные в диаграммы и графики. Интерактивно ею пользоваться трудно, потому что данные нужно класть в URL как запрос. Программа здесь даёт более приятный интерфейс к одной форме данных: по короткому тексту она вызывает сервер диаграмм, чтобы получить QR‑код — матрицу клеток, кодирующую текст. Это изображение можно снять камерой телефона и истолковать, например, как URL, избавив себя от набора URL на крошечной клавиатуре телефона.

> **Сейчас.** Служба `chart.apis.google.com` больше не работает; пример оставлен как в оригинале. `http.ListenAndServe` по‑прежнему жив, но у сервера есть `Shutdown`, а у запроса — `Context`. Введение — в [Writing Web Applications](https://go.dev/doc/articles/wiki/), пакет — [`net/http`](https://pkg.go.dev/net/http).

Вот полная программа. Дальше — объяснение.

```
package main

import (
    "flag"
    "html/template"
    "log"
    "net/http"
)

var addr = flag.String("addr", ":1718", "http service address") // Q=17, R=18

var templ = template.Must(template.New("qr").Parse(templateStr))

func main() {
    flag.Parse()
    http.Handle("/", http.HandlerFunc(QR))
    err := http.ListenAndServe(*addr, nil)
    if err != nil {
        log.Fatal("ListenAndServe:", err)
    }
}

func QR(w http.ResponseWriter, req *http.Request) {
    templ.Execute(w, req.FormValue("s"))
}

const templateStr = `
<html>
<head>
<title>QR Link Generator</title>
</head>
<body>
{{if .}}
<img src="http://chart.apis.google.com/chart?chs=300x300&cht=qr&choe=UTF-8&chl={{.}}" />
<br>
{{.}}
<br>
<br>
{{end}}
<form action="/" name=f method="GET">
    <input maxLength=1024 size=70 name=s value="" title="Text to QR Encode">
    <input type=submit value="Show QR" name=qr>
</form>
</body>
</html>
`
```

Куски до `main` должны быть понятны. Один флаг задаёт порт HTTP нашего сервера по умолчанию. Переменная шаблона `templ` — где начинается интересное. Она строит HTML‑шаблон, который сервер выполнит, чтобы показать страницу; об этом через минуту.

Функция `main` разбирает флаги и, механизмом, о котором мы говорили выше, привязывает функцию `QR` к корневому пути сервера. Затем вызывается `http.ListenAndServe`, чтобы запустить сервер; она блокируется, пока сервер работает.

`QR` просто принимает запрос, в котором есть данные формы, и выполняет шаблон на данных в значении формы с именем `s`.

Пакет шаблонов `html/template` мощен; эта программа лишь касается его возможностей. По сути он на лету переписывает кусок HTML‑текста, подставляя элементы, выведенные из данных, переданных в `templ.Execute`, в данном случае значения формы. В тексте шаблона (`templateStr`) куски, ограниченные двойными скобками, обозначают действия шаблона. Кусок от `{{if .}}` до `{{end}}` выполняется, только если значение текущего данного, называемого `.` (точка), непусто. То есть когда строка пуста, этот кусок шаблона подавляется.

Два фрагмента `{{.}}` говорят показать данные, предъявленные шаблону, — строку запроса — на веб‑странице. Пакет HTML‑шаблонов автоматически даёт подходящее экранирование, так что текст безопасно показывать.

Остальной текст шаблона — просто HTML, который показать при загрузке страницы. Если объяснение слишком быстрое, более подробный разбор — в [документации пакета template](https://pkg.go.dev/html/template).

И вот оно: полезный веб‑сервер в нескольких строках кода плюс управляемый данными HTML‑текст. Go достаточно мощен, чтобы многое происходило в нескольких строках.
