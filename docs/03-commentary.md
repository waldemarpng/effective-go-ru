# Комментарии

[оригинал](https://go.dev/doc/effective_go#commentary)

В Go есть блочные комментарии в стиле C (`/* */`) и строчные в стиле C++ (`//`). Норма — строчные комментарии; блочные чаще встречаются как комментарии пакета, но полезны и внутри выражения, и чтобы отключить большой кусок кода.

Комментарии, которые стоят перед объявлениями верхнего уровня без пустых строк между ними, считаются документацией самого объявления. Эти «doc comments» — основная документация пакета или команды на Go. Подробнее — в «[Go Doc Comments](https://go.dev/doc/comment)».

> **Сейчас.** Правила doc comments по‑прежнему описаны в [Go Doc Comments](https://go.dev/doc/comment). Смотреть документацию удобнее через `go doc` и [pkg.go.dev](https://pkg.go.dev/).
